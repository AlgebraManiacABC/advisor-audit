# Benchmark price data

`etf_prices.csv` is **synthetic placeholder data**, generated by `scripts/make_samples.py` because
market-data sites weren't reachable from the build sandbox. It has the right shape (monthly
total-return prices for VTI and BND) but not real prices, so benchmark returns from it aren't real.

Before showing benchmark numbers as real, run `python scripts/fetch_prices.py` on a machine that
can reach Yahoo Finance, then commit the new CSV and update this note.
